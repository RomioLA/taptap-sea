# 游戏总览

## 核心体验

玩家扮演一名少年，与老人一起出海、捕鱼并逐渐理解海洋。游戏最重要的体验是与老人相处，并运用自己学到的知识改变老人的结局。捕鱼、卖鱼和准备补给提供直观的日常目标；观察、推理和验证让玩家逐步看见更深的故事。

## JAM主题：涌现

简单规则彼此作用，玩家通过行动改变规则运行的局部条件，从而产生可观察、可理解和可再次验证的不同结果。这是核心设计原则，也是圈1需要交付的体验。不能只靠对白解释主题或播放固定演出；投饵、鱼被吸引、捕食和海面信号等已有规则，需要在实际游玩中产生相互关联的反馈。具体内容链仍按已定规则和待决策项落实，不借主题新增未经确认的因果。

## 玩家目标

每一天，玩家可以选择捕鱼、探索、处理事件或回港整理收获。赚钱用于补给和升级，但累计收入不是通关门槛。随着玩家发现鱼群、海面现象、地点和老人言行之间的关系，知识会带来更有效的行动，也会逐步指出改变老人命运的机会。

## 一轮旅程

港口准备 → 出海观察 → 根据线索航行、投饵、捕鱼或探索 → 带着收获回港 → 交易、补给或升级 → 再次出航或结束当天 → 进入次日。

在这条循环中，玩家先从能看见的海面现象作判断，再用行动确认水下发生的变化。鱼、诱饵和捕食关系都依照同一套世界规则运行；玩家的行动可以改变局部条件。普通捕鱼循环也能独立成立，不需要先解开所有故事线索。  
圈2图鉴收录物品、现象及玩家获得的相关知识；基础说明帮助玩家回想对象及其作用。知识须在玩家触发相关内容后出现，具体是首次获得、首次使用或完成其他操作，由每个条目逐项确定。获得新知识时用对话气泡呈现，并让气泡飘入图鉴供之后查阅；知识对话气泡与海面泡泡不同，不从知识提示推导海面泡泡的交互规则。  
高阶规则由玩家联系两条或更多基础规则推理可能结果，暂定收录于图鉴。停船投苹果、小鱼聚集再吸引大鱼仅说明规则组合概念，是否发生、概率和所需时间仍待确定，不当作已验证的连锁效果。代码是否能判定玩家真正发现规则未知，操作序列不能证明因果理解；记录触发与实现方案仍需评估，不预设自动识别玩家推理。

## 老人与知识

前三天老人随行，借共同出海的经历带出观察、实践和交流。第4天开始时按前三天累计交付苹果的结果判定，未达到3个苹果则暂定病死，达到则救活并在第4～7天继续教学；首轮不强制走向死亡，改变结局所需的行动从第一天起就开放。玩家若已掌握知识，首轮也应有机会采取行动。

救法暂定第1～3天累计给老人3个苹果，交付消耗且不恢复玩家体力；判定在第4天开始，救下后继续教导至第7天。病因说明、具体线索、每日对白以及第7天的完整收束正文仍待编写。故事需要让玩家看见普通结果与改变结果的差异，并在结尾留下明确、可尝试的重玩线索。  
圈1第7天结局前安排一次强制剧情事件，表现为捡到漂流瓶并读到纸条。纸条原文：“海岸边那只木桶，下面一定有什么东西，我想多打捞几次就能打捞上来吧。”不直接写出三次或保证宝藏，不给第二次木桶检查额外线索。优先复用普通剧情模态框和文字反馈，不要求新增海上漂流瓶实体、拾取或随机生成系统；一次性触发和周目状态仍需接入。具体结局剧情未定，这条提示不代替完整结局正文。

## 周目与重玩

每轮为7天，昼夜基准保持一致。新一轮重置金钱、体力、升级、背包、地点识别、透镜和普通宝藏状态；玩家现实记忆是主要继承。重玩带来的优势应来自更早读懂海面、找到已知路线和做出不同选择，而不是隐藏的数值加成。  
图鉴与成就系统均安排在圈2，图鉴收录记录和成就记录跨周目保存。新周目保留这些记录，普通玩家资源、地点识别、透镜持有、木桶与剧情进度仍按原规则重置。成就具体项目、条件、文案与表现尚未确定，不由跨周目保存推导出资源继承或数值奖励。
