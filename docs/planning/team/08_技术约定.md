# 技术约定

本页补齐实现约束与程序验收要点，沿用现有工程架构，不新增第二套世界、玩家状态或时钟。已定玩法见对应系统与数值页；候选方案不构成改代码或新增数据字段的授权。

## 现有职责边界

下列架构来自最新工程通知。本机尚未同步架构说明和字段Schema，暂不声称已核对最新代码。后续按正式约定和实际代码落实这些职责；如确需调整边界，先说明原因、影响和最小方案并等待确认。

| 模块 | 职责与接入要求 | 边界 |
|---|---|---|
| Main | Maker生命周期、场景接线 | 不在入口另建玩法状态或第二套更新流程 |
| Game/Game | 整局更新与暂停同步 | 整局更新经既有Game调度 |
| Game/World | Entity注册、生命周期、System调度 | 海洋对象复用共享注册表，不建立第二套世界 |
| EntityFactory、StateMachine、EntityStateSystem | 实体创建、共享FSM和System更新 | 鱼行为沿用共享体系，具体生物内容不能硬塞进通用框架 |
| Ocean | 船鱼行为、生成、碰撞、查询、海洋绘制 | 不复制玩家状态和交易、时钟逻辑 |

| 根data与GeneratedData | items.lua、fish.lua为内容数据来源，生成运行时副本 | 遵循DATA_SCHEMA；新增字段先确认，不把生成副本与根数据作为两份独立源维护 |

## 鱼的状态机

| 对象 | 状态范围 | 约束 |
|---|---|---|
| Sardine | Wander、Attracted、Flee、Avoid | 独立配置小鱼移动与感知数据，不增加Search状态 |
| Tuna | Wander、Attracted、Chase、Avoid | 独立配置大鱼移动与感知数据，不增加Search状态 |
| 共同优先级 | 障碍／边界 > 危险／追猎 > 吸引 > Wander<br>船实际移动时只有小鱼将船作为大鱼同等级危险源，复用现有12米危险感知距离；停船后下一模拟步取消船威胁，不设恢复等待；附近仍有大鱼时小鱼仍逃跑，大鱼不受船惊吓。移动状态按实际位移判断，不增加速度阈值或独立惊扰距离。 | 由既有共享FSM／System组织，不能为鱼另建全局更新骨架 |
| 游荡与逃跑 | 游荡每2～4秒随机改向；小鱼逃跑每0.4秒允许±25°偏转；逃跑时渐进上浮，暂用2秒测试值 | 偏转后仍须总体远离危险，不机械直线逃跑，也不能偏回危险方向<br>上浮期间继续移动且仍可被大鱼捕食，退出逃跑状态后恢复水下；上浮时长待试玩调整 |
| 目标失去与捕食 | Tuna失去猎物2秒后回Wander；1.5米接触捕食会移除Sardine实体<br>每条大鱼成功吃掉一条小鱼后，进入5秒世界时间的捕食冷却；冷却期间不继续追猎／吃下一条小鱼，仍可游荡、避障或受对应诱饵吸引。暂停停止冷却计时。这是未实测的圈1测试值，不要求新增独立饱食状态，也不改变既定移动速度。 | 捕食后5秒冷却为本次确认的未实测基准，不要求新增独立饱食FSM状态；其它生态细则仍见Q-008，不自行扩展规则或字段 |
| 区域生成 | 活跃模拟区域以约20条小鱼／4条大鱼为平衡目标，按区域或群聚组织 | 普通鱼按海域分区初始化：新的一天清理普通鱼并重置分区记录，先生成船周边分区；随后船周围活动范围首次覆盖未初始化分区时按该区生成规则生成鱼，所以驶入新海域仍会遇到新鱼。同一分区同日只初始化一次，离开已访问分区不强制补满，返回保留当天鱼况，被捕或被吃的鱼不会因重访复活。不是全地图240／48，也不实时强制补满；离船和离出发点约束见数值页<br>圈1自然补鱼测试方案：当前屏幕覆盖的实际水域连续10秒世界时间无鱼；符合条件时在屏幕外合法水域补充2～3条小鱼，成功补充间隔至少30秒，离船至少15米。没有合法位置时不强行生成，等待5秒世界时间后重新检查；暂停时停止该等待和其他补鱼计时。局部上限与统计范围仍待定，不把20／4密度目标当作上限。补充不复活已捕走实体，不重置固定地点、宝藏或事件进度，也不在同日重入时强制补满。 |

## 海面信号接入

从现有鱼的位置、活跃状态和FSM派生海面提示，由Ocean维护提示状态，绘制层读取。复用Game的更新与暂停，不另建世界、鱼状态或时钟。0.25秒是状态检查轮询，捕获／被吃等失效事件需立即撤掉对应海鸟；暂停时状态检查、逃跑上浮、海鸟首次俯冲、巡游移动、水花生成与寿命等相关计时和状态进展同步停止。不得用定时装饰海鸟冒充功能信号。

海鸟关联真实活跃且未被捕获的小鱼，小鱼不必处于逃跑状态；每处信号首次出现可俯冲约1.5秒后盘旋，海鸟不捕食鱼。用户提供的当前参数为中心偏移9米、巡游半径3米、每处2只；代码配置与实机表现仍待核验。持续核对巡游提示区域中的有效投饵点与关联鱼距离不超过18米，不能只在首次生成时核对。9米中心偏移加3米巡游半径，在静态几何上最远12米；运动、检查间隔和投放时机仍须验证，且投饵需满足船12米限制。范围成立只说明诱饵可被感知，危险／逃跑优先级不变。鱼离开或冻结后不保留失真提示。大鱼水花从真实经过位置生成，按普通／Chase状态取间隔，用短尾迹表现方向，不用于直接暴露持续精确位置。  
移动时惊鱼、停船不惊仍遵守危险优先级；提示只保证合法投饵处进入感知范围，不保证运动中的船能留住小鱼，老人教学须说明。
