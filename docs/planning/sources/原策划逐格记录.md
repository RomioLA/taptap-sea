## B2

核心设定与核心玩法

## C2

1.1 核心设定
• 玩家扮演一个少年，和老人一起出海。
• 海面下真实存在鱼群、资源、危险、沉船、遗迹等各种东西。
• 玩家一开始只能看到海面，无法直接知道水下发生了什么。
• 玩家需要通过鱼群跳出水面、海鸟聚集、漂浮物出现、某些生物改变行动等现象，推测海下情况。

1.2 核心体验
• 核心不是“直接寻找资源”。
• 基本过程是：观察现象 → 推测原因 → 做出行动 → 验证自己的判断。
• 整体最重要的感觉是：海洋不会直接告诉玩家答案，玩家需要逐渐学会“读懂海”。

## D2

例如：
• 大鱼追小鱼。
• 小鱼被逼到水面。
• 海鸟开始聚集。
• 玩家远处看到鸟群。
• 玩家推测水下可能正在发生捕食。
• 再决定过去捕鱼、观察或者绕开。

## E2

• 游戏最终目标目前没有完全确定，可能是宝藏、赚钱或者其他目标。

## B3

世界规则与涌现玩法

## C3

2.1 基础规则
• 游戏里的规则本身尽量简单、固定、容易理解。
• 不同规则之间会互相影响。
• 已经举出的基础规则包括：大鱼追小鱼、小鱼遇到危险会逃、海鸟寻找鱼群、鱼饵吸引小鱼、小鱼吸引大鱼、某些鱼只出现在特定环境等。

2.2 玩家行为参与规则
• 玩家不仅观察规则，也可以通过自己的行为改变规则运行的条件。
• 不同的行为触发不同规则，不同规则继续相互交织，最后形成不同结果。
• 因此玩家很早做出的一个行为，也可能造成后面完全不同的结果。

## D3

已讨论过的一组示例规则：
1. 抛下鱼饵会吸引小鱼。
2. 小鱼会吸引大鱼。
3. 大鱼不存在时（例如被捕捞完），鲸鱼才会出现。
4. 鲸鱼栖息地有宝藏。
5. 没有小鱼时鲸鱼会死。
6. 鲸鱼死的地方会出现美人鱼。

于是玩家第一天“要不要抛鱼饵”“要不要捕完小鱼或大鱼”，就可能造成后续不同的蝴蝶效应。

## E3

• 上述鲸鱼、美人鱼等只是用于说明这种玩法，并不是已经确定必须采用的正式规则。
• 需要继续设计真正采用哪些基础规则，以及规则之间怎么组合。

## B4

老人、教学与一周目结构

## C4

3.1 老人教学
• 前3天/年老人陪少年出海。
• 老人教授一些基础、容易理解的规律。
• 已提出的内容包括：大鱼追小鱼、小鱼遇到危险会逃、海鸟寻找鱼群、某些漂浮物意味着附近可能有特殊地点、某些鱼只出现在特定环境。
• 教学不是纯文字说明，而是老人带玩家实际观察、实践和验证。

3.2 老人离开
• 原始设定是第4天/年老人去世或离开。
• 后续讨论进一步倾向于：一周目老人发生死亡事件，而且最好具有明显的情感冲击。
• 老人离开以后，玩家失去直接指导，只能自己继续观察和总结规则。

3.3 一周目不能全部是教学
• 一周目需要从一开始就有正常游戏目标。
• 目前倾向以捕鱼、赚钱等作为一周目的直接目标。
• 老人的教学应该融合在正常游玩过程中，而不是前三天全部变成教程。

## D4

一周目大致可以形成：
• 玩家以捕鱼、赚钱等为直接目标。
• 同时老人顺便教授基础规则。
• 中途突然发生老人死亡事件。
• 玩家之后独自继续游戏，并逐渐发现更深的世界规则。

## E4

• “3天/第4天”还是“3年/第4年”尚未确定。
• 老人最终一定死亡，还是也可能以其他方式离开，尚未完全锁定；目前讨论重点明显更偏向“一周目死亡”。

## B5

特殊事件、宝藏与触发条件

## C5

4.1 特殊事件
• 特殊事件尽量不是简单按照“第几天固定触发”。
• 更希望由各种条件和规则自然形成。
• 已提出：鱼大量聚集可能引来大型生物；持续出现漂浮木板可能意味着附近有沉船；某些生物异常逃散可能意味着附近有危险；特定环境、生物和时间同时满足可能出现稀有事件或遗迹线索。

4.2 宝藏
• 宝藏从第一天开始就真实存在，而不是后期才生成。
• 如果玩家已经知道全部规则，理论上第一天就可能找到宝藏。
• 某些宝藏可以是固定位置，但玩家一开始不知道找到它的方法。

4.3 固定条件可以存在，但不能太多
• 可以有少量每周目固定发生的条件或时间点。
• 但如果这种固定内容太多，会削弱由规则运行产生结果的感觉。

## D5

固定宝藏例子：
• 某个能透视海底的宝藏一直在固定位置。
• 玩家一开始不知道“鱼在转圈的地方有宝藏”这条规则。
• 一周目可能很晚才偶然发现。
• 已经知道规则的玩家，可以第一天看到鱼转圈后直接去拿。

固定天气例子：
• 假设第3天和第6天固定下雨。
• 假设规则是“前一天下雨，第二天神秘商人出现”。
• 一周目玩家第3天不知道规则，可能第7天才遇到商人。
• 二周目玩家已经知道，就可能第4天提前找到商人并完成交易。
• 但讨论中已经明确说明：下雨、商人都只是举例，正式游戏不一定这样设计。

## E5

• 需要确定固定事件到底有多少。
• “鱼群盘旋、鲸群出现、海鸟聚集都可能说明有宝藏”时，如果玩家都做出了正确判断，是否每一种情况下面都一定应该真的有宝藏，这一点讨论中提出过但没有定论。

## B6

玩家知识成长与透视镜

## C6

5.1 核心成长
• 游戏成长的重点不是单纯升级角色数值，而是玩家自己越来越理解世界。
• 玩家知道的规则越多，就越能提前找到东西、判断事件，甚至主动制造某些条件。

5.2 透视镜
• 一个重要宝藏可以是“透视镜”。
• 获得前：玩家只能通过海面现象推测海下情况。
• 获得后：玩家可以直接看到海面下的鱼群、危险和环境。
• 它还可以用来验证玩家之前对于各种规律的理解到底对不对。
• 这种奖励属于“获得新的认知能力”，而不是普通攻击力、速度之类的数值升级。

## D6

这个概念的重点不是：
“游戏规定新玩家必须第6～7天才能拿到。”

而是：
规则第一天就已经存在，只是新玩家不知道。

例如透视镜一直在固定位置，规则是“鱼群转圈的位置有宝藏”。
• 一周目玩家不知道，可能第6～7天才发现。
• 二周目玩家记得规则，就可以第一天直接去拿。

世界没变，变的是玩家知道的东西。

## E6

• 透视镜获得以后具体怎么看海底、是否会影响原本“推测海底”的核心玩法，目前还没有进一步确定。

## B7

基础循环、明面目标与装备成长

## C7

6.1 基础循环
目前可以暂定：
港口准备 → 出海 → 观察海面现象 → 判断海下情况 → 选择航向或行动 → 捕鱼 / 获得资源 / 触发事件 / 寻找遗迹 → 回港结算 → 判断今天是否还能再次出航→下一天继续探索。

6.2 明面目标
• 可以把捕鱼、赚钱、维持生活作为玩家最直接能理解的目标。
• 一周目尤其可以以赚钱作为主要目标，让玩家在不知道隐藏规则时仍然有明确事情可做。

6.3 隐藏目标
• 理解老人留下的知识。
• 寻找遗迹。
• 寻找某个最终宝藏，或者其他隐藏目标。

6.4 装备 / 船只成长
• 原始设想中提到可以赚钱、升级装备或船只。
• 后续讨论认为这部分并不急，甚至可以不做复杂升级。

## D7

最开始可以让玩家认为：
“我的目标就是捕鱼赚钱。”

随着游戏进行，才慢慢发现：
• 世界里存在更多规律。
• 老人的死亡可能不是绝对不可改变。
• 宝藏和特殊事件可以提前找到。
• 游戏实际上还有更深层的探索目标。

## E7

• 游戏最终的“主目标”仍然待定：可能是赚钱、宝藏，也可能是别的。
• 船只升级是否需要，以及具体怎么体现，目前明确属于“不急、可以继续讨论”的部分。

## B8

多周目、剧情分支与探索目标

## C8

7.1 一周目
• 主要以赚钱、捕鱼和正常探索为目标。
• 玩家学习部分规则。
• 老人发生死亡等重要事件，形成情感冲击。

7.2 二周目
• 玩家利用已经知道的规则进行探索。
• 可以更早拿宝藏、更早发现特殊事件。
• 有机会改变一周目发生过的事情。
• 其中一个重要方向是尝试拯救老人。

7.3 三、四周目及以后
• 如果玩家愿意继续玩，可以进一步探索制作组埋藏的所有线索和特殊事件。
• 多周目的变化主要来自玩家知识，而不是重新练数值。

## D8

例如：
• 一周目第三天出现某个条件，但玩家不知道意义，因此没能利用。
• 后来才知道它可以导向某个宝藏、特殊角色或者其他办法。
• 二周目提前利用这个知识，就可能改变第四天老人原本死亡的结果。

讨论中也提出过其他可能：
• 也许打捞某个宝藏可以救老人。
• 也许遇见美人鱼以后，老人并不是死亡，而是跟美人鱼离开。

这些都只是可能的剧情例子，还没有确定。

## E8

• 救下老人之后老人有什么用，讨论中明确提出过这个问题。
• 已提出的一个可能性是：老人继续存在可以提高捕鱼效率。
• 目前只确认“可以有实际作用”，具体作用尚未确定，不能继续补充其他功能。

## B9

成就、视角与角色待定项

## C9

8.1 成就系统
• 可以加入成就系统。
• 玩家探索到某个特殊事件，就点亮对应成就。
• 用于支撑三、四周目继续寻找隐藏内容。

8.2 视角
• 已经明确讨论游戏首先是2D。
• 在俯瞰海洋和横切视角之间，当前讨论选择了横切。
• 但横切存在明显问题：如果海上、海下各占一半，玩家就会直接透视海底，与核心设定冲突。
• 当前诉求是：先尝试一种横切但不透视海底的视觉风格，看看会不会显得违和。

8.3 主角
• 提出过少年是否应该设计男版、女版，让玩家选择。

## D9

这里目前没有进一步确定具体表现方案。

只能确定问题本身：
既想采用横切视角，又不能让玩家一开始直接看到海下内容。

## E9

• 需要做“不透视海底”的横切视觉方案验证。
• 少年是否提供男版 / 女版仍待定。

## D12

1. 玩家基础数值
玩家只保留一个主要数值：体力。
- 捕鱼会消耗体力。
- 部分打捞、探索行为也可以消耗少量体力。
- 食物用于恢复体力。
- 不增加饥饿、口渴、精神等额外生存数值，避免系统过重。
- 体力不足时，玩家需要考虑继续探索还是提前回港。
2. 物品系统
主要物品包括：
- 鱼
- 鱼饵
- 食物
- 宝藏
- 漂流物
- 奇怪物品 / 稀有物品
- 信件、遗物等剧情物品
所有物品统一提供三个基础选项：
1. 使用
2. 丢弃
3. 给老人
“使用”的实际效果根据物品类型不同而变化。
例如：
- 鱼：吃掉恢复体力，或者保留回港出售。
- 食物：食用后恢复体力。
- 鱼饵：投入海中，影响附近鱼群。
- 宝藏：查看、装备或触发特殊能力。
- 特殊物品：可能用于探索、事件或其他用途。
3. 给老人
“给老人”既承担教学，也承担角色塑造。
不同东西交给老人会得到不同反馈。
例如：
- 食物给老人：不一定产生数值收益，但老人会根据食物产生不同回复。
- 鱼饵给老人：老人会解释鱼饵的用途，以及与鱼群有关的更深规则。
- 捕到的鱼给老人看：可能得到称赞、评价或者关于这种鱼的知识。
- 奇怪物品或宝藏给老人：可能触发特殊对话、世界观信息或新的线索。
因此玩家可以选择：
自己使用获得即时收益
或者交给老人获得信息和知识。

4. 背包与回港
船上拥有有限的物品栏。
物品栏满后：
- 可以丢弃不重要物品；
- 可以使用部分物品腾出空间；
- 或者选择回港。
回港以后可以：
- 出售捕获的鱼；
- 购买食物；
- 购买鱼饵；
- 补充基础物资；
- 升级船只；
- 进行剧情或结算。
这样物品栏本身也会自然形成：
继续探索还是带着已有收获回港

的选择。
5. 一天如何结束
推荐采用：
行动推进时间 + 玩家可以主动回港。

一天可以简单分为：
清晨 → 上午 → 中午 → 下午 → 黄昏
以下行为会推进时间：
- 航行
- 捕鱼
- 打捞
- 调查特殊现象
- 进行部分事件
玩家任何时候都可以选择提前回港。
到了黄昏或一天结束时，则必须回港。
这样：
- 体力限制玩家一天能做多少高消耗行动；
- 时间限制玩家一天能够探索多远；
- 玩家需要判断“继续追这个现象，还是先回港”。
不采用现实时间倒计时，也暂时不采用“每天固定只能出航几次”。
6. 船只成长
船只成长保持轻量，主要提供便利，不直接替代玩家对规则的理解。
目前可以确定：
物品栏
升级船舱，提高可携带物品数量。
作用：
一次出海可以带回更多鱼、宝藏和其他物品。

捕捞能力
升级捕鱼设备，使捕鱼消耗更少体力。
例如可以从简单工具逐渐升级为更高效的捕鱼设备。
作用：
同样的体力可以完成更多捕鱼或探索。

船速
升级船只速度。
作用：
同样的一天内能够航行更远，更容易赶到玩家观察到的特殊现象附近。

观察能力
暂时待定。
目前游戏没有迷雾机制，因此“增加观察距离”是否有实际意义还需要结合最终画面和视角设计后再决定。
7. 成长结构
游戏中可以形成两种不同的成长：
金钱成长
捕鱼 → 回港出售 → 获得金钱 → 买食物、鱼饵和升级船只。
主要解决：
玩家行动效率和探索便利性。

知识成长
观察现象 → 实验 → 老人教学 → 自己总结 → 理解更多世界规则。
主要解决：
玩家越来越会“读海”。

一些真正改变玩法的能力，例如透视海底的“透视镜”，不建议直接花钱购买，而应该作为特殊宝藏，通过理解规则和探索获得。
因此整体成长可以概括为：
钱让玩家做事情更方便，知识让玩家真正变得更强。

## D20

1. 一周目与二周目目标
- 一周目的主要目标确定为赚钱。
- 宝藏也可以卖钱，因此宝藏在一周目也能服务于赚钱目标。
- 二周目之后的目标转向：
  - 救老人
  - 世界解谜
- 暗线故事目前待定，方向是通过宝藏上的物品进行串联。
2. 一天的时间结构
- 游戏内每一天分为白天和晚上。
- 白天约 2 分钟。
- 晚上约 1 分钟。
- 除了特殊事件以及回港休整时暂停时间，其他时候时间正常流逝。
- 黄昏会通过太阳位置明显提示。
- 晚上看不到正常的海面和水下情况，鼓励玩家早点回港。
- 如果回港太晚，第二天出发时会扣除初始体力。
- 夜晚可以存在少量专属现象，例如：
  - 远处灯光
  - 发光生物
  - 特殊宝藏
3. 每天事件数量
- 前期每天大约 3 个事件。
- 后期每天大约 5 个事件。
- 后期能处理更多事件，和以下因素有关：
  - 船速提高
  - 玩家操作熟练度提高
  - 玩家是否愿意晚上继续出行
4. 透视镜
- 透视镜不是全屏透视。
- 玩家只能看到“放大镜范围内”的水下内容。
- 用于避免获得透视镜后直接破坏原本“读海”的核心玩法。
5. 地图与远距离识别
- 不采用传统战争迷雾。
- 远处可以看到地点或海岛的轮廓，但一开始不知道具体是什么。
- 玩家靠近并完成识别后，以后再次看到时，可以一眼判断它是什么。
- 也就是说，地点的“识别能力”会随着探索而解锁。
6. 轻量成长系统
玩家只保留一个主要数值：
- 体力
体力相关：
- 捕鱼消耗体力。
- 食物可以恢复体力。
- 回港太晚会影响第二天初始体力。
物品类型包括：
- 鱼
- 鱼饵
- 食物
- 宝藏
- 漂流物
- 奇怪物品 / 稀有物品
- 信件、遗物等剧情物品
所有物品统一有三个基础选项：
1. 使用
2. 丢弃
3. 给老人
不同物品的“使用”效果不同。
7. 给老人
- 食物给老人：不影响数值，但会触发不同回复。
- 鱼饵给老人：老人会教更深的知识，例如鱼饵的使用规则。
- 捕获的鱼给老人看：可以获得称赞或知识。
- 宝藏、特殊物品也可以给老人，用于获得相关反馈或信息。
8. 背包与回港
- 船上有有限物品栏。
- 物品满了以后，可以：
  - 使用物品
  - 丢弃物品
  - 回港
- 回港后可以：
  - 卖鱼
  - 买食物
  - 补给
  - 升级船只
9. 船只成长
目前确定或倾向保留的成长方向：
- 物品栏容量
- 捕捞时消耗更少体力
- 船速
观察能力暂时待定，因为目前没有迷雾系统。
10. 航海主画面
- 当前更倾向主要航海画面使用俯瞰视角。
- 正常状态下：
  - 海面是不透明的
  - 玩家只能看到海面现象
  - 水下内容隐藏
- 透视镜开启后：
  - 海面仍然存在
  - 只在透视范围内看到水下内容
- 水上和水下需要通过明显的视觉层级区分。
