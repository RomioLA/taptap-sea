**二、十项实际行为**

1. **捕鱼扣体力时刻、空网**

   `BeginFishing` 不扣体力；有效的 `CompleteFishing` 在交付事务中扣 **40**。有效空网完成也扣40；同一完成 token 重复调用不会重复扣费。失败交付会回滚体力。

   当前没有自动执行的四秒动作或进度条；`durationSec=4` 是配置，完成接口也没有强制等待四秒。[完成事务](C:/codex/taptap-sea/scripts/Integration/Bridge.lua:328)、[成本配置](C:/codex/taptap-sea/scripts/config/gameplay.lua:11)。

2. **满舱与完成时无空间**

   满舱不能开始，检查发生在查询鱼之前。完成时再次要求至少一个空位，**空网也要通过这个检查**。若此时无空间，返回失败，不扣体力、不移除鱼；待完成 token 保留。没有自动出售、丢弃或替换渔获。[开始检查](C:/codex/taptap-sea/scripts/Integration/Bridge.lua:245)。

3. **捕获目标选定与鱼的行为**

   在 `BeginFishing` 时，以抛网中心8m内最近的一条鱼选定目标；抛网中心距船最多30m。隐藏鱼仍可选中。

   选中后不冻结、不预留、不停止普通 AI，沙丁鱼仍可能被金枪鱼吃掉。完成时检查原目标是否还存在；失效则失败且不扣费，不另选鱼。**完成时没有重新检查鱼是否仍在网内或船附近。**[目标查询](C:/codex/taptap-sea/scripts/Ocean/SeaRuntime.lua:127)、[捕食](C:/codex/taptap-sea/scripts/Ocean/Fish.lua:192)。

4. **捕鱼期间其他操作**

   当前 pending 捕鱼 token 没有全局动作锁，因此接口层允许继续航行、投物、打开背包／老人界面、暂停或返港。打开暂停界面后，海洋模拟暂停，捕鱼完成检查也会被暂停状态拒绝。

   正式打捞流程未实现，只有成本接口和开发按钮；不能据此确认“捕鱼期间可以正式打捞”。默认 HUD 也没有正式捕鱼按钮。[动作条件](C:/codex/taptap-sea/scripts/Gameplay/Loop.lua:244)、[当前 HUD 操作栏](C:/codex/taptap-sea/scripts/Gameplay/HUD.lua:205)。

5. **取消捕鱼**

   `CancelFishing(token)` 已实现：取消待完成 token，不扣体力，不改变目标鱼或背包。没有正式取消按钮；已完成 token 不能取消。[取消接口](C:/codex/taptap-sea/scripts/Integration/Bridge.lua:406)。

6. **透视镜**

   已有底层 `revealWithScope(center,durationSec)`：中心由调用者提供并复制，揭示半径 **20m**，中心不会随船移动；持续时间由调用者传入，按海洋模拟时间递减。

   该接口没有最大观察距离校验、使用期间移动限制或物品持有检查。正式透视镜使用／获取流程未实现。Debug 全局显示水下与这个局部揭示接口是两个功能。[揭示入口](C:/codex/taptap-sea/scripts/Ocean/SeaRuntime.lua:146)、[揭示生命周期](C:/codex/taptap-sea/scripts/Ocean/World.lua:233)。

7. **暂停**

   B 时钟的暂停状态经 Bridge 同步到 A。暂停期间，鱼 AI、船移动、投放物寿命和局部揭示倒计时均停止。

   捕鱼进度未实现；现有 token 不计时，暂停不会自动取消它，恢复后仍可能完成。[同步与更新](C:/codex/taptap-sea/scripts/Integration/Bridge.lua:186)、[海洋更新](C:/codex/taptap-sea/scripts/Ocean/SeaRuntime.lua:165)。

8. **换日与同日返回**

   B 首次应用结算时推进天数、计算体力、重置时钟和商店库存；**存档成功后**才调用 A 刷新普通鱼、清除临时物与揭示、重置区域生成标记及捕鱼 token。

   钱、背包、升级、识别和故事／老人数据保留；固定岛屿和船保留，船不搬回港口。普通换日也没有清除原航行目标。

   保存失败时，B 已应用下一天，但结算锁保留，A 尚未刷新；重试不会重复增加天数。同一天离开已初始化区域再回来不重新生成鱼，捕获后也不立即补鱼。[日结](C:/codex/taptap-sea/scripts/Gameplay/Loop.lua:151)、[世界刷新](C:/codex/taptap-sea/scripts/Integration/Bridge.lua:70)、[区域生成](C:/codex/taptap-sea/scripts/Ocean/SeaRuntime.lua:53)。

9. **夜晚结束、返港与次日体力**

   白天120秒、夜晚60秒。夜晚耗尽后暂停并出现强制返港确认；确认后设置港口状态并进入结算。**没有自动航行或传送回港口坐标。**

   普通结算次日体力为：最大体力减去夜间超过30秒的逐秒处罚，向下取整，最低0。强制返港为最大体力的50%，向下取整。不是沿用当天剩余体力。[返港与体力计算](C:/codex/taptap-sea/scripts/Gameplay/Loop.lua:131)。

10. **老人展示／赠送、关键道具**

    “只展示物品”未实现。赠送在接收成功后移除一件物品，记录 `elder.lastGivenItemId`；拒绝或异常不消耗。当前默认接收方只是收下提示，没有对白分支、任务或命运判断。[赠送](C:/codex/taptap-sea/scripts/Gameplay/Loop.lua:290)。

    物品表只有苹果、鱼饵、沙丁鱼、金枪鱼，未定义透视镜或其他关键道具，因此关键道具能否出售／丢弃**尚未实现**。当前出售按 `sellPrice>0` 判断，丢弃没有关键物品保护规则。[物品定义](C:/codex/taptap-sea/scripts/data/items.lua)、[出售](C:/codex/taptap-sea/scripts/Gameplay/Loop.lua:321)。
