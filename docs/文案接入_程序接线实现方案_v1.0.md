## 0. 结论速览

1. **入口已半成型**：「记事本」按钮早已存在（`HUD.lua:603`，dock 位宽 72），当前打开的是「成就/图鉴」双 tab 模态。本次是**改造**不是新建：双 tab → 「航海日志 / 记忆碎片」二选一。
2. **图鉴/成就拆解有现成地基**：成就执行器 `AchievementSystem`（A1~A6 + C1~C3，跨周目落 profile）已接线，但 HUD 图鉴页读的是**内存桩** `Achievements.lua`（6 条占位、零持久化）——这是本次要修的核心断线。
3. **航海日志 / 六轨碎片 / 主动气泡 / firstSeen 在代码与 xlsx 中均不存在**，需新建 3 个数据模块 + 1 个气泡枢纽 + 1 份碎片数据表；ID 前缀需新建（`log_` / `bub_` / `mem_`，与既有 W-/S-/C-/Q- 等 8 套编号防撞名）。
4. **老人对话改造是净删除 + 小改**：聊天记录抽屉节点删（测试早已断言「不得有聊天记录按钮」），对话记录从「跨天保留」改「每次拜访独立会话」。
5. **暂停语义**：新增两个时钟理由 `"log"` / `"fragments"`，完全复用 `GameClock:Pause/Resume` 既有机制；气泡、选择面板、碎片网格浏览**不暂停**。
6. **测试契约零冲突可期**：现有 4 套件对记事本/图鉴页**零断言**（grep 证实）；老人对话契约（`elderDialogueScroll` id、开场+2/+4 气泡计数、展示×2）全部保留。新增 1 套 `Circle1B12NotebookTests` 覆盖新行为。

## 3. 数据模型与 ID 体系

### 3.1 文案 ID 新前缀（防撞名）

xlsx 现存 8 套编号：`W-`（文案条目）、`S-`/`S`、`P-`、`Q-`、`C-`/`C0x`、`A-/B-/D-`、`R/E-`、世界对象 ID（`port_01` 等）。**新建三套小写技术 ID**（与 W-xx 文案编号一对一映射但不混用）：

| 前缀 | 用途 | 示例 | 说明 |
|---|---|---|---|
| `log_` | 航海日志条目 | `log_barrel_stage3`、`log_paper`、`log_ending_saved` | 自动补条目唯一键，once 去重依此 |
| `bub_` | 主动气泡类型 | `bub_cue_birds`、`bub_mem_found`、`bub_reject_generic` | firstSeen 依此去重 |
| `mem_` | 记忆碎片格 | `mem_fish_01`…；**保留** `memory_island_01/02`、`memory_treasure_01` 原 ID | 保留旧 ID 避免动 `WorldContentActions`/treasures 链路 |

### 3.2 航海日志条目模型

```lua
-- 条目（validMap 兼容：全 string/number 字段）
{
  id       = "log_barrel_stage3",   -- 唯一键（log_ 前缀）
  week     = 1,                      -- 周目
  day      = 3,                      -- 日期（写入时快照）
  title    = "木桶里的透镜",          -- 分组标题用
  body     = "……",                  -- 正文（数值定上限，默认 300 字）
  source   = "system",              -- "system"=自动补 | "note"=玩家手记
  linkId   = "memory_treasure_01",  -- 关联碎片格（可空）
}
```

**存储位置决策（推荐 A）**：

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 主档 `player.story.circle1B2.logEntries`（推荐）** | 与 `paperShown` 等同生命周期；随检查点保存语义天然一致；Restore 走既有 `validMap` | 需扩展 Snapshot/Restore + `Progress.Validate`；云档体积增长（有护栏） |
| B. ProfileStore 新增 `logs` | 不碰主档 schema | 语义错位——profile 是跨周目元数据，日志是周目记录 |
| C. 独立本地文件 | 主档零风险 | 与双写语义分裂，云不同步 |

选 A。实施要点：
- 新建 `LogProgress` 风格校验（仿 `Circle1B2Progress`：Initialize/Validate/Snapshot/Restore 四件套），条目字段全 string/number，`source ∈ {system, note}`，`id` 唯一，条数/字数上限护栏（工程默认：**80 条/周目、正文 300 字**，具体值交数值 §3.3）。
- 手记护栏：**60 字/条、3 条/天**（工程默认，数值可调）。
- 云体积风险：80 条 × ~150 字 ≈ 12KB JSON，量级安全；上限即护栏。

### 3.3 记忆碎片六轨模型

```lua

tracks = { "fish", "bird", "weather", "wreck", "light", "anomaly", "relic" }
-- 条目：{ id="mem_fish_01", track="fish", name=..., desc=..., source=... }
```

| 新轨 | 数据来源 | 状态 |

| 鱼 | `knowledge.lua` domains.fish（K-fish-1~3） | ✅ 可映射 |
| 鸟 | domains.bird（K-bird-1~3） | ✅ 可映射 |
| 异常 | domains.anomaly（K-abn-1/3） | ✅ 可映射 |

### 3.4 firstSeen（气泡首触）语义

## 4. 接口设计（Loop 新 API）

仿 `SetElderOpen`（`Loop.lua:609-627`）同款守卫（busy/pendingCatch/storyDialog/barrel 等）+ `CancelAutoReturn` + 时钟暂停：

| API | 签名 | 行为 |
|---|---|---|
| 日志开合 | `Loop:SetLogOpen(open)` | `clock:Pause("log")/Resume("log")`；返回 `(ok, reason)` |
| 碎片网格开合 | `Loop:SetFragmentGridOpen(open)` | **不暂停**（§2.3 字面语义；预留 `pauseGrid` 入参供数值反转决策） |
| 碎片翻看开合 | `Loop:SetFragmentDetailOpen(open)` | `Pause("fragments")/Resume("fragments")` |
| 写日志 | `Loop:AppendLog(entry)` | `LogStore.Append`：once 去重（同 id 本周目只写一次）+ 护栏校验 |
| 玩家手记 | `Loop:WritePlayerNote(text)` | 长度/每日条数校验 → `AppendLog{source="note"}` |
| 读日志 | `Loop:GetLogEntries()` | 按 (week, day) 分组返回（HUD 建组标题） |
| 碎片态 | `Loop:GetFragmentStates()` | `{ [track] = { seen=N, total=M }, entries={...} }` |
| 成就态 | `Loop:GetAchievementStates()` | 转调 `AchievementSystem.IsUnlocked/HasAchievement`（A1~A6 必含，C1~C3 可选） |
| 气泡 | `Loop:NotifyBubble(type, text, linkId)` | `BubbleHub.Show`：firstSeen 门控 + 频率限制；HUD 每帧 Poll 渲染 |
| 跳转 | `Loop:JumpToEntry(linkId)` | 打开对应视图并定位（log→条目；mem_→点亮格） |
| 未读 | `Loop:GetNotebookUnread()` / `MarkNotebookRead()` | 新日志/新碎块置位，打开记事本清除（驱动按钮角标） |

模块级 API（纯逻辑，可测）：

```lua
LogStore.New{ data } -> { Append(entry)->ok,reason; Entries(); Snapshot(player); Restore(player); Validate(player) }
FragmentStore.New{ data, profile } -> { MarkSeen(id, week); IsSeen(id); GetTracks(); MarkUnseen? }
BubbleHub.New{ config } -> { Show(type, text, linkId)->shown|gated|throttled; Poll()->msg|nil; Update(dt); ResetRun() }
```
