# 保存失败后继续换日：本地修复记录

本记录仅用于本地完整版，不属于本轮共享交付。来源：用户本轮要求“在无法保存时选择放弃保存进入下一天”。

## 行为

- 日结保存失败后保留重试，并显示“放弃本次保存，继续”。不会自动跳过保存。
- 放弃只允许在保存已失败、结算已应用且没有在途保存/读档时执行。
- 解除结算暂停，调用同一新日接口刷新海洋与临时动作，日期、次日体力和商店不再重复计算。
- 状态明确为 skipped，HUD 提示本次结算未保存；不会伪装保存成功或删除/改写旧存档。
- 重复点击或迟到回调不会再次换日。下一次日结继续走正常保存。
- 这里只修复换日阻塞，不代表已接通正式云存档，也不改变返港坐标、捕鱼扣费或其它玩法规则。
