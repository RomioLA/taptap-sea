## Issue 清单与验收标准

### C1-HUD-01：补齐基础状态、物品信息和当前模式

**方向：**

- 鱼获只显示稀有度：沙丁鱼为“普通”，金枪鱼为“稀有”。这是 HUD 标记，不改变掉率、价格、存档规则，也不伪造重量。
- 空背包时给出明确引导；没有可出售鱼获时给出对应引导。
- 提供统一的当前操作模式提示，覆盖现有可触发的操作状态；不得借此新增玩法规则。
- 增加独立、无格数限制的宝物栏入口或呈现区，只展示现有 `scopeLens`。宝物不占普通船舱格，也不增加出售、丢弃或投放行为。
- 港口实际距离和是否处于 10 米范围内持续显示；远海时也不隐藏距离提示。

**验收：**

- 鱼获行稳定显示“沙丁鱼·普通”与“金枪鱼·稀有”；现有价格、捕获判定、库存容量和保存数据不因标签改变。
- 空背包和无可售鱼两种空状态分别显示明确且可执行的提示；非空状态不显示空状态文案。
- 玩家进入和退出捕鱼选点、透镜开关、投放选择及港口/海上状态后，统一模式提示与真实状态同步，不出现过期或互相矛盾的模式。
- 普通船舱容量变化不影响宝物栏；宝物栏只呈现已有透镜状态，不出现新宝物或新事件。
- 港距在近港、10 米边界内外及远海均持续可见；距离对应船中心与实际港口，范围文字与 10 米判定一致。

### C1-HUD-02：守住满舱选点与老人交付的点击边界

**方向：**

- 满舱时仅允许明确承载选点穿透逻辑的背景遮罩处理海面点击；按钮、抽屉和其他 UI 控件仍拦截点击。一般空白 UI 区域不作为穿透例外。
- 从背包选择给老人时，先打开实际老人对话，再执行交付。
- 老人离开后，交付入口保持可操作；点击后解释不可用原因，不置灰隐藏。

**验收：**

- 满舱待接收期间，点击明确的背景遮罩可选择合法投放点；点击 HUD 按钮、背包抽屉、物品操作按钮或其他 UI 不会变成海面点击或投放。
- 给老人操作先呈现真实对话界面，再提交交付；失败时物品不误扣，成功时沿用已定物品消耗规则。
- 老人不在场时，点击交付能看到具体原因；不会静默失败或错误消耗物品。

### C1-HUD-03：明确商店售罄与购买失败反馈

**方向：**

- 商店售罄的购买按钮禁用，并显示库存/售罄原因。
- 购买失败时让玩家看懂没有买成；不扣金钱、不改变库存。

**验收：**

- 库存为零时按钮处于禁用状态，界面同时说明售罄或补货状态。
- 金钱不足或购买失败时显示对应原因，金钱和库存维持失败前状态。
- 有库存且购买成功时，按钮和库存显示随结果正确更新。

### C1-HUD-04：抽离表现辅助并保留响应式布局边界

**方向：**

- 使用引擎 `backgroundColor` transition 连续插值完成颜色变化，不做跳变式换肤。
- 把 HUD 表现辅助抽到 `scripts/Gameplay/HUDPresentation.lua`，使 `scripts/Gameplay/HUD.lua` 从当前 1,632 行降到 1,500 行以下。
- Scene 左侧栏宽度适配不得覆盖 absolute 定位的操作坞、抽屉和遮罩布局。

**验收：**

- 昼夜或主题变化时背景色通过引擎 transition 连续变化；切换期间无闪烁、残留动画或主题状态不一致。
- 表现辅助集中在 `HUDPresentation.lua`；`HUD.lua` 少于 1,500 行，业务状态和规则仍由原有模块维护。
- 改变窗口宽度、UI scale 或 DPR 时，左侧内容按设计宽度适配；absolute 操作坞仍锚定屏幕右下，抽屉仍锚定底部，模态遮罩仍覆盖全屏。
- 适配代码不通过给所有根子项统一写宽度而改写上述 absolute 元素的位置或尺寸。
