- `scripts/Ocean/SurfaceSignals.lua`：锁定时同步清除对应功能海鸟组，不等待轮询。

## 共同接口

- `LockFishingTarget(id, ownerToken)`：有效鱼、table token；同 owner 重复锁定成功；其他 owner 返回 `fishing_target_locked`；无效鱼返回 `fishing_target_expired`，无效 token 返回 `invalid_capture_owner`。锁不改变 active/frozen、FSM 和上浮进度，立即撤销海鸟。
- `UnlockFishingTarget(id, ownerToken)`：对象身份匹配才解除；不同 owner 返回 `capture_owner_mismatch`；已移除/已解锁幂等成功；无效 token 返回 `invalid_capture_owner`。鱼与行为对象保留原身份。
- `RemoveFishingTarget(id, ownerToken?)`：锁定鱼要求匹配 token，否则 `false, "capture_owner_mismatch"`；未锁定鱼保留单参数兼容；显式传入旧 token 不能移除无锁的新 ID。移除原因仍是 `caught`，行为清理由既有 `ForgetFishingBehavior` 完成。
- `SnapshotFishingTarget` / `RestoreFishingTarget`：保留实体、注册位置、活动/冻结、FSM 状态、行为引用与 overlap 原契约，增加锁和 owner；拒绝不同 World、不同捕鱼世代、不同目标对象、重用 ID 或其他 owner 的陈旧恢复。所有 owner 比较使用 `rawequal`，保证 opaque table 的对象身份语义。
- `selectFishingTarget`：仍使用 30 米抛网距离、8 米网半径，最近单鱼、稳定等距顺序；不排除隐藏/冻结鱼；合法空网返回 nil，无错误。确认合法位置时不选鱼。

捕食冷却位于 FishBehavior 的运行态 `predationCooldownUntil`，从成功 `world:remove(..., "eaten")` 的世界时间开始。5 秒内无追猎/再次捕食，游荡、避障和匹配诱饵吸引保留；捕食失败不删猎物、不启动冷却。暂停不推进海洋时间，单鱼冻结或捕获锁定只停 AI；恢复时按实际世界时间判断冷却，未新建昼夜时钟、饱食状态或存档字段。

保留已接受的上浮 2 秒测试值、海鸟不捕食、俯冲与水花规则及参数。
