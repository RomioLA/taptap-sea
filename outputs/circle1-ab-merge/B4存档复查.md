## 未验服务边界与明确非缺陷

1. **初始保存选择跳过。** 若玩家在初始 Set 失败或等待中主动选择“不保存继续”，`Loop.lua:513-521` 会继续游戏；文案明确提示旧云档可能在下次启动时恢复，HUD `:1197-1212` 也说明旧云档仍保留。这是明示的无保存选择，不是“新局已可靠覆盖旧档”的保证。
2. **远端同 key ordering。** 超时或跳过只隔离本地回调；`Persistence.Cloud` 没有取消 Set 或远端版本仲裁。接口矩阵 `outputs/circle1-ab-merge/接口验收矩阵.md:53` 已明确说明，旧请求/新请求的本地身份校验不能证明服务端写入顺序，真实云和跨启动恢复仍待验。没有真实服务证据，故只列未验边界，不报成已复现的远端乱序 Bug。
3. **延后内容。** B4 未改变 `PlayerState`/`Persistence` schema；当前快照没有新增图鉴、成就或 Day 7 正式结局字段，符合接口矩阵 `:11-13, 53` 的圈1范围。
