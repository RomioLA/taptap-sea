## 供 B 使用的接口

```lua
local barrel = runtime:GetFixedBarrel()
-- nil，或独立只读快照：
-- { id=实体ID, contentId="driftwood_barrel",
--   generation=世界重建代次, position={x=60,y=25} }

if barrel then
    local allowed, reason = runtime:CanInteractWithBarrel(barrel.id, barrel.generation)
end
```

每次 Get 返回新快照，顶层和嵌套 position 的普通写入报错；不存在可修改世界的引用。接口匹配当前登记的精确对象，不搜索最近漂浮物，也不以 contentId 相同替换对象。移除、死亡、非法位置或登记对象被替换时 Get 返回 nil。

CanInteract 检查代次、存在性、身份和船中心到桶中心的距离，复用 `Config.interaction.operateDistance`，**5 米包含**。成功返回 true；失败原因如下，按检查顺序返回：

| reason | 含义 |
| --- | --- |
| `barrel_generation_mismatch` | 凭证代次与当前世界不符，包括新局后 ID 重用的旧凭证 |
| `barrel_unavailable` | 当前木桶不存在、死亡、移除、位置失效或登记身份失效 |
| `barrel_identity_mismatch` | ID 不是这只固定木桶 |
| `invalid_ship_position` | 船位置不是有效有限坐标 |
| `barrel_out_of_range` | 船到木桶超过既有 5 米操作距离 |

generation 是进程内的重建凭证，不是检查次数、阶段或新增存档字段；每次 World 重建更新，鱼群刷新及正常跨日不更新。接口不扣体力、不发苹果/鱼饵/透镜、不打开故事 UI，也不开始或结束行动。

原接口保持兼容：船前方 20 米、总夹角 90°的 `SetScopeEnabled` / `IsScopeEnabled`；独立旧定时圆形揭示；可选 `options.getFishingView()`；`SeaDraw.Scene` 第五时钟、第六捕鱼快照；航行目标写入前调用 `onSeaPointer(position,runtime,ocean)`，true 消费、false/nil 沿用航行。UI 命中、触摸、DPR 和合法海域守卫未更改。正式透镜按钮与权限、捕鱼/木桶玩家规则由 B 接入。
