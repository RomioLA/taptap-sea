## 可验收流程

| 要求 | 已实现行为与证据 |
| --- | --- |
| 选择网心 → 确认 → 进度 → 取消/结果 | 正式 `Integration.Scene` 接入 B HUD；鼠标/触摸海面输入转发选点。按钮、进度、免费取消及结果通过 `GameLoopUISpec` 控件树与回调测试。 |
| 确认不选鱼；0.5 秒落网；4 秒完成 | 确认只检查网心、接口与起手体力。落网边界一次同步 select + Lock，最多一条；锁失败不补选，合法空网保持空结果，4 秒完成。 |
| 39/40 体力边界与收费 | 起手至少40；成功只扣40。空网、失败、取消、未完成夜尽均免费，已流逝世界时间不退还。 |
| 世界继续；船不能移动；背包不能打开 | 唯一 World 每帧调度 Gameplay System 一次；依动作边界推进时钟和海洋，分段共享原海洋单帧预算。移动目标清除、键盘轴归零；未通过全世界暂停阻止移动。 |
| 暂停、大 dt、夜尽、世代 | 暂停停止动作进度；同帧夜尽先中止未完成动作；世代变更拒绝旧 token，不向新 World 恢复旧鱼。清锁或恢复未成功时保持技术状态继续重试，未清理完不得强返/换日。 |
| 满舱仍可起手；腾格再接收 | 成功移除鱼并扣费后保留待接收收获，强制开舱。不能关整个船舱，可返回物品子菜单；使用、老人赠送、丢弃沿用普通物品规则。老人不在时明确解释。 |
| 接收不丢失、不重复 | 足够格子才允许领取；领取不再扣费或移除鱼。未领取前禁止新捕鱼、结算、读档、新周目和场景替换；夜尽保留已完成收获。 |
| 异常与重复操作 | opaque table token、终态收据及完整库存快照保证重放。覆盖收费、库存添加、世界移除后抛错；领取恢复失败时先恢复再重试，禁止其他库存编辑。普通物品移除先于外部交接，交接拒绝恢复库存；恢复未完成保持屏障。 |
| 关键状态保护 | 普通背包目前只有 apple/bait/sardine/tuna。测试证明使用/丢弃/领取不会修改既有独立 treasures 状态；没有新增宝藏物品、关键物品字段或保护规则。 |
| Reset/停止场景 | 未完成动作需解除持有锁。待接收收获、库存回滚或清锁未完成时拒绝破坏性场景替换；不丢弃收据或恢复记录。 |

动作记录、收据、库存回滚均由 Gameplay 持有；Integration 仅引用模块并转发输入/同步调用。没有正式 Runtime 替身，没有直接写海洋鱼状态，没有新增存档字段。

## 手动窗口验收（待A接口合并后）

由用户在确认需要本地窗口试玩时启动已有固定版本 CLI：

```powershell
& 'C:/ALL/APP/nodejs/node.exe' 'C:/Users/Administrator.DESKTOP-NS4I6RF/.taptap-maker/mcp-runtime/0.0.36/dist/maker.js' preview start --target-dir C:/codex/taptap-sea --json
```

1. 出航，点“捕鱼 · 选择网心”，鼠标/触摸选合法网心再确认；确认前不抓鱼，约0.5秒锁定、4秒才出结果。空网不扣费，成功只扣40；39体力不能起手、40可以。
2. 动作中点海面、按移动键、点背包：船不移动、背包不开，其他鱼和临时物仍运行。暂停后进度停止，恢复继续；取消免费。
3. 满舱抛网并成功：自动开舱并提示空间不足，不能关舱；“操作→返回”只退出子菜单；老人不在时赠送解释原因。使用普通物品，或在空白海面选12米内投放点后丢弃，腾格再点“领取渔获”。
4. 连续点领取、再次调用完成或取消：库存只增加一次，不再次收费。领取后舱可以关闭；满舱空网不要求腾格。
5. 靠近夜尽开始未完成捕鱼、暂停/恢复、Reset或停止场景：确认免费中断、无残留锁。已完成待接收收获保持；需先领取才允许换日/新周目/场景替换。故障注入由专属测试覆盖。
