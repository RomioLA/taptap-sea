## Runtime 接口：A 实现，B 调用

保留现有方法签名与返回语义：

| 方法 | 本轮约定 |
| --- | --- |
| `canCastNet(center)` | 确认时验证合法水域和距船 30 米；不选择鱼。 |
| `selectFishingTarget(center, radius?, filter?)` | B 在约 0.5 秒落网时调用，网半径仍为 Config 中的 8 米，返回最近未锁定有效鱼或 nil；合法空网没有错误，非法位置仍返回既有错误。隐藏/冻结不排除捕鱼资格。 |
| `GetFishingTarget(id)` | 返回当前鱼实体或 nil，B 不直接改鱼字段。 |
| `GetFishingGeneration()` | 维持原世代契约，用于拒绝重置/换日后的旧事务。 |
| `SnapshotFishingTarget(target)` / `RestoreFishingTarget(target, snapshot)` | 延续原回滚契约，A 补充捕获锁与 owner token 状态，保证失败后实体、行为和锁恢复一致。 |
| `RemoveFishingTarget(id, ownerToken?)` | A 添加可选 ownerToken；锁定鱼仅匹配 token 可移除，否则 `false, "capture_owner_mismatch"`。未锁定鱼保持既有单参数兼容。移除原因仍为 caught，提示即时失效。 |
| `ForgetFishingBehavior(id)` | 沿用原方法，成功移除后清理行为。 |

新增方法名固定：

```lua
Runtime:LockFishingTarget(id, ownerToken) --> true | false, reason?
Runtime:UnlockFishingTarget(id, ownerToken) --> true | false, reason?
```

- ownerToken 是 B 创建的 opaque table，按对象身份匹配；不能使用可重复的编号替代。
- Lock：目标必须是仍存在的有效鱼。不存在/不是有效鱼返回 `false, "fishing_target_expired"`；非 table token 返回 `false, "invalid_capture_owner"`；其他 owner 已锁定返回 `false, "fishing_target_locked"`；同 owner 重复调用返回 true。
- Lock 成功设置 `captureLocked=true`，立即禁止 AI/再次选鱼/捕食并撤销功能海鸟；不删鱼。A 自行选择内部 owner 存储，B 不依赖内部字段。
- Unlock：非 table token 返回 `false, "invalid_capture_owner"`；鱼存在且由其他 owner 锁定返回 `false, "capture_owner_mismatch"`；匹配 owner 解除并返回 true。已移除或已经解锁也返回 true，便于取消/重置路径幂等清理。
- B 一次落网同步执行 select 和 Lock，不在两次调用间等待异步操作。无鱼时记录空网；锁失败免费失败，不重新挑鱼。
- B 先比较 Runtime 世代，陈旧 token 不能完成捕获。A 的 owner 校验也必须防止旧 ID 被重用时错误解锁或移除新鱼。
- 成功、取消、失败、中断的每条路径都必须明确锁的最终归属；A 管世界状态，B 管动作 token、费用、待接收收获和界面。

## 计时与操作归属

A 的模拟计时依附既有海洋子步，不自建昼夜时钟。B 的动作计时依附现有 Gameplay 世界时间，协调 0.5 秒落网与 4 秒结束边界，负责整帧跨界、暂停、夜尽与输入屏蔽；只在 B 所有文件修改接线，不要求 A 改 Game/Gameplay。

捕鱼期间禁止船移动属于输入/动作规则，不能通过全世界暂停实现。满舱接收属于 B 的背包流程，A 不接触库存、体力或 UI。
